# Plan de trabajo XP

## Duración

El proyecto se divide en cuatro iteraciones de duración uniforme.

## Iteración 1: Base técnica y proveedores

- Inicialización del repositorio.
- Arquitectura modular.
- Documentación XP inicial.
- PostgreSQL y Docker Compose.
- Integración continua inicial.
- CRUD de proveedores.
- Normalización y unicidad.
- MVC y API REST.
- Pruebas unitarias e integración.

### Liberación esperada

Registrar y consultar proveedores válidos desde navegador y API,
rechazando nombres duplicados.

## Iteración 2: Licitaciones

- CRUD de licitaciones.
- Código único.
- Presupuesto.
- Fecha de cierre.
- Estados Borrador, Publicada y Cerrada.
- Transiciones permitidas.
- Pruebas correspondientes.

## Iteración 3: Ofertas y evaluación

- CRUD de ofertas.
- Oferta duplicada.
- Oferta vencida.
- Límite presupuestario.
- Mejor oferta.
- Clasificación del ahorro.
- Niveles de aprobación.
- Conversión CRC/USD.

## Iteración 4: Integración y despliegue

- Landing page.
- Interfaz completa.
- Modo claro y oscuro.
- Pruebas funcionales.
- Cobertura.
- Docker completo.
- Kubernetes.
- GitHub Actions completo.
- Documentación y liberación final.
